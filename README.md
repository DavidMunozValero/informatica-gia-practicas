# Informática GIA — Prácticas y Ejercicios

Notebooks de ejercicios y prácticas para la asignatura de **Informática**
del Grado en Ingeniería Aeroespacial (UCLM).

## Cómo usar estos notebooks

1. Haz clic en el enlace "Abrir en Colab" del material web.
2. En Colab: **Archivo > Guardar una copia en Drive**.
3. Trabaja en tu copia y guarda los cambios.
4. Entrega el notebook según las indicaciones del profesor.

## Estructura

- `ejercicios/` — Notebooks con enunciados de ejercicios por tema.
- `practicas/` — Notebooks de prácticas del aula de ordenadores.
